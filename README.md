# Telegram VPN Sync

Автоматически берёт подписку из последнего поста Telegram-канала.

Источник:

https://t.me/happvpn

## Ключевой принцип

Домен источника НЕ захардкожен.

Например сегодня пост может содержать:

```text
happ://crypt5/...
https://chyra.ru/exec?...
tg://proxy?...
```

Будет выбрано:

```text
https://chyra.ru/exec?...
```

А если завтра будет:

```text
happ://crypt5/...
https://another-site.example/sub/123
tg://proxy?...
```

будет выбрано:

```text
https://another-site.example/sub/123
```

Если послезавтра будет IP:

```text
http://77.110.104.181:5002/sub/abc
```

будет выбран именно он.

Никакой проверки на `chyra.ru` нет.

## Remarks

Флаг определяется из исходного `remarks`.

```text
🇮🇱 Израиль @RadexVPN
```

становится:

```text
🇮🇱 Израиль #1
```

Если исходное имя содержит `LTE` в любом месте:

```text
🇩🇪 LTE Обход глушилок
```

становится:

```text
🇩🇪 🏳 Германия #1
```

`LTE` проверяется без учёта регистра.

Европейский автоматический сервер:

```text
🇪🇺 что угодно
```

становится:

```text
🇪🇺 АВТО ⚡
```

Счётчики обычных и LTE-конфигов независимы.

## GitHub Actions

Запускается каждые 15 минут или вручную.

1. Открывает последний публичный пост.
2. Находит HTTP(S)-ссылки.
3. Берёт первую.
4. Скачивает файл.
5. Разбирает JSON.
6. Меняет remarks.
7. Записывает `data/subscription.json`.
8. Записывает `public/subscription.json`.
9. Валидирует результат.
10. Делает commit и push.

Vercel раздаёт:

`/subscription.json`

Имя профиля передаётся через ASCII HTTP-заголовок `profile-title: OokVPN`.
